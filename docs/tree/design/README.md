# Passive tree design drafts

Working outputs of [docs/PASSIVE-TREE.md](../../PASSIVE-TREE.md), one file per phase step, saved as each finishes so they
can be read at any time. A = what the tree must serve, B = what good trees have in common (one file per game, then the
comparison), C = the design brief (user stop 1), D = the build (one file per region), E = checks, F = the finished tree.
