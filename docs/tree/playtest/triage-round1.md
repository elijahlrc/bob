# Round 1: twelve simulated players, and what was done (T6.1 and T6.2)

Twelve agents built about 100 points each on the tree of commit `c9cbc72` (two per class, home and off-class briefs; reports in
`round1/`). A complaint was acted on only after it was checked against the tree data, and a player's suggested fix was taken only
where it was the right fix. Verdicts: **confirmed** (two or more players, or shown in the data), **plausible** (one player, fits the
principles), **artifact** (the tool, a misreading, an intended cost), **later** (real, but outside "small changes within the spec":
a new node, new engine work, a game rule).

## Not done, on purpose

- A named bridge between regions, the great wheels and the other cluster shapes (the plan's cheapest items): with the ring of the
  middle joining every region, no player asked for a bridge. Round 2 may.
- New nodes of any kind (D5).
